# Ảnh kỷ niệm (Photos)

Bỏ ảnh vào thư mục này với tên `1.jpg`, `2.jpg`, `3.jpg`… theo thứ tự muốn hiện trong album.

- Trên GitHub: **Add file** → **Upload files** → kéo ảnh vào → **Commit changes**.
- Muốn thêm ảnh thứ 7 trở đi hoặc ghi chú dưới ảnh: sửa danh sách `photos` trong `config.js`.
- Hướng dẫn đầy đủ nằm ở `README.md` ngoài cùng.
